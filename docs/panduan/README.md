# Materi tambahan bot Bantuan

Berkas `.md`, `.txt`, atau `.pdf` di folder ini otomatis diindeks ke basis
pengetahuan bot Bantuan ComputeHub (Qdrant, koleksi `computehub_help`) paling
lambat satu jam setelah backend membacanya. Berkas `README.md` ini sendiri
tidak ikut diindeks.

Tips agar jawaban bot tepat:

- Pakai judul bagian (`## Judul`) yang jelas; potongan teks tidak melintasi judul.
- Tulis langkah demi langkah dengan bahasa yang mudah dipahami mahasiswa.
- Jangan menulis alamat IP, kata sandi, atau data rahasia lain.
